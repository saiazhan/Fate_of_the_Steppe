# Степная судьба · Дала тағдыры · Fate of the Steppe

Адаптивный прототип визуальной новеллы на HTML, CSS и JavaScript.

## Запуск
Откройте `index.html` в браузере. Все игровые ресурсы подключаются локально; для музыки браузеру потребуется первое нажатие/касание пользователя. Для чтения музыкального каталога из JSON при локальном запуске может понадобиться локальный веб-сервер или оболочка приложения.

## Локализация меню
Переводы всего текущего интерфейса находятся в `locales/menu.json` (русский, казахский и английский). Переводы сюжетных глав будут храниться отдельно — в собственных JSON-файлах соответствующих глав.

## Экраны
- главное меню на фоне степи;
- чёрный тестовый экран «Новая игра»;
- настройки в юрте: аудио, видео, прочее;
- меню загрузки с демонстрационными пустыми слотами;
- меню «Прочее»;
- галерея с шестью ячейками на страницу и перелистыванием;
- музыкальная комната со списком композиций из `sounds/main_menu/music_library.json`;
- заготовки разделов «Достижения» и «Об игре».

## Музыкальная комната
Каталог находится в `sounds/main_menu/music_library.json`. Добавляй объекты в массив `tracks` по образцу:
- `id` — уникальный идентификатор;
- `title` — название композиции;
- `artist` — исполнитель;
- `description` — описание;
- `src` — путь к аудиофайлу относительно корня игры, например `sounds/main_menu/steppe_theme.mp3`;
- `loop` — зацикливать ли композицию.

Сам JSON-файл уже создан, массив пока пустой. Когда добавляешь трек, положи аудиофайл в папку `sounds` и укажи его имя в `src`.

## Адаптивность
Интерфейс перестраивается под узкие экраны и сенсорное управление. На телефонах пункт полноэкранного режима скрывается. Новые панели также имеют мобильную компоновку, но требуют отдельной проверки на реальных устройствах.

## Пока не реализовано
Сюжет, игровые сохранения, разблокировка CG по ходу прохождения, настоящие достижения, финальное наполнение страницы «Об игре», озвучка, анимация фонов и нативные сборки EXE/APK. Слоты загрузки пока демонстрационные пустые элементы интерфейса.
