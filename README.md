# Степная судьба · Дала тағдыры · Fate of the Steppe

Прототип визуальной новеллы на HTML, CSS и JavaScript.

## Запуск
Откройте `index.html` в современном браузере. Интернет для работы интерфейса не нужен.

## Первый объединённый прототип
- главное меню на фоне степи;
- переход в настройки внутри юрты и возврат в главное меню;
- вкладки «Аудио», «Видео», «Прочее»;
- громкость музыки, звуков и будущей озвучки;
- полноэкранный режим, выбор предполагаемого размера окна;
- скорость и размер текста, параметры пропуска и авто-продолжения;
- сохранение настроек в localStorage.

## Фоновые изображения
Поместите изображения в папку `assets`:
- `steppe-background.jpg` — панорама степи для главного меню;
- `yurt-settings.jpg` — интерьер юрты для настроек.

Фон юрты автоматически отражается по горизонтали через CSS. Если изображений нет, интерфейс покажет запасной однотонный фон.

## Пока не реализовано
Сюжет, игровые сохранения, аудиоплеер, озвучка, анимация огня/облаков и нативные сборки EXE/APK. Полноэкранный режим работает в браузере; точное управление размером окна будет доступно в настольной оболочке.
