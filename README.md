# Степная судьба · Дала тағдыры · Fate of the Steppe

Адаптивный прототип визуальной новеллы на HTML, CSS и JavaScript.

## Запуск
Откройте `index.html` в браузере. Все ресурсы подключаются локально; для музыки браузеру потребуется первое нажатие/касание пользователя.

## Экраны
- главное меню на фоне степи;
- чёрный тестовый экран «Новая игра» с возвратом назад;
- настройки в юрте: аудио, видео, прочее;
- меню загрузки с фоном `assets/safe_river.jpg`, слотами и кнопками загрузки/удаления.

## Адаптивность
Интерфейс перестраивается под узкие экраны и сенсорное управление. На телефонах пункт полноэкранного режима скрывается. Панели настроек и загрузки расположены справа на широком экране и переходят в потоковую мобильную компоновку.

## Ресурсы
- `assets/steppe-background.jpg` — главное меню;
- `assets/yurt-settings.jpg` — настройки (отражается по горизонтали);
- `assets/safe_river.jpg` — загрузка сохранений;
- `sounds/main_menu_sounds.mp3` — музыка главного меню;
- `sounds/settings_sounds.mp3` — музыка настроек;
- `sounds/safe_load_sounds.mp3` — музыка экрана загрузки.

Музыка зациклена. Из-за ограничений браузера она начинает играть после первого действия пользователя. Если аудиофайл не найден по указанному пути, браузер просто не сможет его воспроизвести.

## Пока не реализовано
Сами игровые сохранения, сюжет, аудиоплеер звуковых эффектов, озвучка, анимация фонов, нативные сборки EXE/APK. Слоты пока демонстрационные пустые элементы интерфейса.
