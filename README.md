# Степная судьба · Дала тағдыры · Fate of the Steppe

Небольшой проект визуальной новеллы на HTML, CSS и JavaScript.

## Языки названия
- Русский: **Степная судьба**
- Қазақша: **Дала тағдыры**
- English: **Fate of the Steppe**

## Сейчас
В репозитории создаётся первый прототип интерфейса настроек:
- три вкладки: «Аудио», «Видео», «Прочее»;
- громкость музыки, звуков и будущей озвучки персонажей;
- режим отображения и варианты размера окна;
- язык интерфейса (пока русский по умолчанию);
- скорость и размер текста;
- параметры пропуска и автоматического продолжения;
- сохранение параметров в localStorage.

## Запуск
Открой `index.html` в современном браузере. Для этого прототипа интернет не требуется.

## Иллюстрация юрты
Ожидаемый путь: `assets/yurt-settings.jpg`. CSS отражает изображение по горизонтали. Сам файл иллюстрации ещё нужно добавить в репозиторий.
